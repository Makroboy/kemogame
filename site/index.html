PICK UP & PLAY

How to play

Collect all the musical notes in the level. Avoid the wrong notes fired by the loudspeakers.

On a computer, use a keyboard or click the on-screen buttons. On a phone or tablet, use the touch controls. The instructions below cover Windows PCs, Macs, iPads, iPhones and Android devices.

Start a game

  1. Click or tap Start game and wait for the game to load. This takes a moment, especially the first time.
  2. Click or tap Options or press O to open the Options menu.
  3. Select New game with the keyboard or on-screen ↑ / ↓ buttons and press Enter or tap OK.
  4. Choose a character with the keyboard or on-screen ← / → buttons, then press Enter or tap OK to play.

Phones, tablets and touchscreens

Use the arrow buttons to move and jump, OK to confirm, and Options / Back for the game’s menu actions. The labels at the bottom of the game screen show their current functions.

On a touchscreen, hold ← or → and tap ↑ with another finger to jump while moving.

Full screen hides the phone and enlarges the game. On a phone or tablet, play in portrait orientation.

After completing a level

Press Enter / OK to skip the level-clear celebration, or let it finish automatically. If you return to the title screen, use Options → New game to open character selection. Choose another character with ← / → and press Enter / OK. A character marked Level clear! has already been completed.

Original sound

The title screen has its own tune. During play, collecting a note or taking a hit triggers a short sound; there is no continuous gameplay backing track in the original game. Completing a character’s level plays that character’s tune. Game over and completing all characters have separate tunes. Use Sound: on in the game’s Options menu and press a game control to enable browser audio.

Original phone controls

The number keys still work: 4 / 6 to move, 1 / 2 / 3 to jump, and 5 to confirm. Open Original keypad below the controls to show the Nokia keypad.

Press a game control to enable audio. Internet connection required for the browser runtime.

MOBILE KEMOPETROL · 2002

The story of KemoGame

In 2002, Kemopetrol got its own mobile game.

A game for the Nokia 7650

KemoGame was made as part of Mobile Kemopetrol, a project led by Hewlett-Packard’s Mobile E-Services Bazaar. Finnish game developer Sumea created the J2ME platform game for the Nokia 7650.

You play as one of the band’s five members, collecting musical notes and avoiding loudspeakers that fire wrong notes. Each band member has a level of their own.

The project seems to have explored ways to offer something extra to people buying records, at a time when record labels were looking for ways to counter music piracy.

Visit Sumea’s website from 2004.

Goodbye on a mobile phone

Mobile Kemopetrol also brought the band’s music video for Goodbye to mobile phones. It was the world’s first music video available to stream on a mobile phone.

The project website

kemopetrolmusic.com was created for the Mobile Kemopetrol project. The band also ran its own websites, kemopetrol.org and kemopetrol.com.

Getting the game off the phone

To recover the game from the old Nokia 7650, a replacement battery was bought and a two-way infrared dongle was found. The broken power switch had to be removed, and the contacts on the circuit board connected with a paper clip.

Nokia PC Suite was installed on a Windows computer, along with a file-access application on the phone. The original files could then be copied to the computer.

This browser version runs the original game.

Original credits

The game’s About screen lists:

The recovered files

The recovered package includes KemoGame.jar, which contains the game and its graphics, characters, sounds and levels; KemoGame.jad, the installation descriptor; the original Symbian installation metadata; and rms.db, the database used for scores and settings.

The game was built for MIDP 1.0 / CLDC 1.0.
